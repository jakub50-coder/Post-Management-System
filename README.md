Post Management Application

A Python-based application that interacts with the JSONPlaceholder REST API to retrieve and create posts.

Features:
- Retrieve and display all available posts.
- Retrieve an individual post using its ID.
- Create new posts using POST requests.
- Process JSON responses from an external API.
- Handle HTTP request errors.
- Validate user input, including empty fields and invalid numeric values.
- Interactive menu for navigating the application.

Technologies Used:
- Python 3
- Requests library
- REST APIs
- JSON
- HTTP methods (GET and POST)

Installation and Setup:

Clone the repository: git clone 

Install the required dependency: python -m pip install requests

Run the application: python main.py

API Information
- This project uses JSONPlaceholder, a free fake REST API for testing and practicing API interactions.

Learning Objectives:
This project demonstrates practical use of Python functions, loops, dictionaries, exception handling, input validation, HTTP requests, and JSON data processing.
